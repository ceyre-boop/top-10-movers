# CEILING — TOP10 Ceiling Estimation

Status: reserved for Phase 2

## Goal

Estimate the share of positive label days driven by:

- scheduled catalysts
- carryover momentum
- unscheduled news

## Method

- Sample 200 positive label instances from the pre-holdout period
- Classify each as scheduled, carryover, or unscheduled using a fixed rubric
- Record the unscheduled share as the practical recall ceiling

## Reporting

Write the ceiling estimate here before any holdout evaluation is performed.
