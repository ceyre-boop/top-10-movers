# EXP-001 — First live data run (Databento smoke test)

- **Date:** 2026-08-29
- **Counts toward family-wise correction?** NO — this is a data-plumbing
  validation, not a model variant. No model was fit.
- **Spend:** $1.68 of the $125 Databento credit.

## Hypothesis
The pipeline can produce a valid, survivorship-bias-free top-10 label set
from real Databento data, and the §2.5 sanity checks will catch it if not.

## Setup
- Venues: XNAS.ITCH, XNYS.PILLAR, XASE.PILLAR (`ohlcv-1d`, `ALL_SYMBOLS`)
- Window: 2022-06-01 → 2022-08-01 (pre-holdout)
- Filters: common stock only, listed XNYS/XNAS/XASE, prior close >= $1.00,
  ADV >= $1M, prior bar within 4 calendar days

## Result: PASS, after three real defects were found and fixed

Final label set (XNAS, last 12 sessions, per-day symbol resolution):
- **median top-10 gainer +17.39%** (min +16.15%, max +26.17%)
- ~2,950 names/day universe, 0 duplicate (date, ticker) rows

Ground-truth spot check — these are recognizable, correct movers:
- HKD 2022-07-28 $71.98 -> $185.00 (+157%), 07-29 -> $370.00 (+100%).
  AMTD Digital, the defining squeeze of summer 2022.
- SIGA +29.5%, GOVX +45.5% — monkeypox names, correct for that window.
- MARA / CORZ / PLUG / BE / NOVA — crypto miners and solar, correct.

## Defects found (all silent, all would have produced a confident wrong model)

1. **instrument_id is reassigned daily.** LULU: 6844, 6843, 6839, 6840,
   6841, 6837 on consecutive sessions. A range-wide symbology.resolve
   labels one id with one ticker for the whole range, mismapping most
   rows. Produced a median top-10 gainer of **+8702%**.
   Fix: resolve per trading day.
2. **ts_event is UTC midnight of the trade date.** Converting to ET
   shifts every bar back a day and manufactures Sunday sessions
   (a "2022-06-05" row appeared; that was a Sunday).
3. **No consolidated US equities dataset exists before 2023.**
   EQUS.SUMMARY starts 2024-07-01; DBEQ.BASIC/EQUS.MINI 2023-03-28 —
   all inside the holdout. Only the three listing-venue feeds reach
   2018-05-01, so the universe must be their union.

## Notes that change the plan
- The sanity tripwire worked. It caught the contaminated label set three
  times before any model saw it.
- The valid run's median gainer (+17.39%) sits BELOW the spec's +20%
  floor. Under the original single-bound check this correct run would
  have hard-aborted the pipeline — vindicating the split into a hard
  upper bound (contamination) and a soft lower warning (quiet regime).
- Per-venue volume understates consolidated volume, so the $1M ADV
  filter admits fewer names than a SIP-based filter would.
- Databento flagged 2022-07-18 and 2022-07-25 as degraded.
