# EXP-003 — First walk-forward on real data (T1, XNAS)

- **Date:** 2026-09-01
- **Counts toward family-wise correction?** **YES** — first fitted model
  variant. One variant tested so far.
- **Spend:** $0 (uses EXP-002 data)

## Setup
- Universe: XNAS common stock + ADR, prior close >= $1, 20d ADV >= $1M,
  split days and 16 degraded sessions excluded
- 1,485,694 rows | 1,147 sessions | 3,571 tickers | 11,470 positives
- After feature warmup: 1,309,718 rows, 1,087 sessions, 0.589% positive
- Model: LightGBM binary, expanding-window walk-forward, yearly retrain
- 15 T1 features, all prior-close only

## Result

| Method | hits/day | precision@10 |
|---|---|---|
| B0 random | 0.084 | 0.84% |
| B1 yesterday's top 10 | 0.433 | 4.33% |
| B2 5-day realized vol | 0.603 | 6.03% |
| B2b 20-day realized vol | 0.521 | 5.21% |
| B2c prior relative volume | 0.352 | 3.52% |
| **Model** | **0.660** | **6.60%** |

Per-year vs B2: 2020 +0.100, 2021 +0.076, 2022 +0.045. **Beat 3/3.**

`scale_pos_weight` 133.7 / 148.2 / 170.5 — a genuine imbalance, not the
1.0 degenerate fallback. Lower than the ~400 anticipated because the
universe is ~1,256 names/day, not the ~4,000 the plan assumed.

## This does NOT meet the pre-registered criterion

PREREG requires beating **B4** (premarket gap) by >= 1.0 hits/day.
This beats **B2** by 0.07. Two independent reasons that is not the claim:

1. **B4 is not measured.** It needs premarket minute bars, which have
   not been pulled. The plan expects B4 alone at 3-5 hits/day — roughly
   5x this model. Beating a volatility baseline says nothing about
   clearing B4.
2. **The edge shrinks as training data grows** (+0.100 -> +0.076 ->
   +0.045). A real signal usually strengthens. This pattern is
   consistent with the early margin being noise.

This is T1 (prior close only). The plan expects T1's ceiling well below
T2's, so a weak T1 is consistent with the design, not a refutation.

## Assumptions this run overturned

| Plan assumed | Measured |
|---|---|
| median top-10 gain +20%..+60% | 10.9%-18.5% — **below the floor every year** |
| split contamination ~25% of slots | 0.06% (7 rows) |
| universe ~4,000 names/day | 1,256/day |

The median-gain result is decisive: a hard +20% floor would have aborted
**all five years**. Splitting that check into a hard upper bound and a
soft lower warning was load-bearing, not stylistic.

Split contamination is low because the $1M ADV and $1 price filters
already exclude nearly all reverse-split microcaps — the liquidity
filter does most of P4's work before the split join is consulted.
